<h1>💡 SmartHome Light Control (IoT)</h1>

<p>
This project is a simple IoT application that allows users to control a smart light
through a web browser.
</p>

<hr>

<h2>✅ What This Application Does</h2>

<ul>
  <li>Turn a smart light ON and OFF</li>
  <li>Display the current light state</li>
  <li>Work in any modern web browser</li>
  <li>Run on Windows, macOS, and Linux</li>
</ul>

<hr>

<h2>⚙️ Requirements</h2>

<ul>
  <li>.NET SDK (version 7 or higher)</li>
  <li>Web browser (Chrome, Edge, Firefox, Safari)</li>
</ul>

<hr>

<h2>🚀 How to Run the Application</h2>

<h3>1️⃣ Start the Backend</h3>

<p>
Open a terminal in the project folder and run:
</p>

<pre>
dotnet run
</pre>

<p>
When the application starts, the terminal will show an address similar to:
</p>

<pre>
http://localhost:9999
</pre>

<p>
Keep the backend running.
</p>

<hr>

<h3>2️⃣ Open the Web Interface</h3>

<p>
Open a web browser and navigate to:
</p>

<pre>
http://localhost:5213/
</pre>
